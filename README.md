# LSTM Next Word Prediction

## Project Overview

This project predicts the next word based on user-entered text using an LSTM deep learning model.

## Features

* Next-word prediction
* Text input interface
* NLP text processing
* Interactive Streamlit application

## Technologies Used

* Python
* TensorFlow/Keras
* LSTM
* Natural Language Processing
* Streamlit

## How to Run

Install dependencies:

`pip install -r requirements.txt`

Run the application:

`streamlit run app.py`
